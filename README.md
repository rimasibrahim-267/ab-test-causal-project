# مشروع تقييم تجربة A/B والاستدلال السببي

## 1. معلومات الدورة والجهة
- **اسم الدورة:** برنامج التجارب واختبارات A/B والاستدلال السببي (من تصميم التجربة إلى القرار).
- **الجهة المنظمة:** أكاديمية سدايا (SDAIA Academy).
- **رابط حساب الأكاديمية على GitHub:** [https://github.com/SDAIAAcademy](https://github.com/SDAIAAcademy)


## 2. وصف المشكلة والفرضية- 

- **السؤال الرئيسي:** هل يؤدي إرسال إشعار فوري (Push Notification) يتضمن رسالة تحفيزية إلى زيادة معدل إتمام الشراء؟
- **الفرضية:** إذا تم إرسال إشعار فوري تحفيزي، فسترتفع نسبة إتمام الشراء نتيجة تحفيز المستخدم وتقليل التسرب.

## 3. هيكلة الملفات البرمجية
- `day1_design.py`: تصميم التجربة، التوزيع الثابت (Hash)، وفحوصات الثقة (A/A وSRM).
- `day2_analysis.py`: حجم العينة، المدة، وطريقة CUPED لتقليل التباين.
- `day3_quasi.py`: معالجة الاطلاع المبكر (Peeking) وتطبيق الفروق في الفروق (DiD).
- `day4_causal.py`: الرسوم السببية، معيار الباب الخلفي، وقاعدة القرار.
- `main.py`: الملف الرئيسي لتشغيل المنظومة متكاملة.

## 4. طريقة التشغيل
لتشغيل المشروع كاملاً والتأكد من عمل الأكواد دون أخطاء:
```bash
python main.py
## 5. النتائج والتوصية النهائية
- **القرار:** إطلاق الميزة بحذر نظراً لتحسن معدل إتمام الشراء بثقة إحصائية واضحة مع سلامة مقاييس الحماية.
- **القيود:** اقتصرت التجربة على مدة أسبوعين، ويُفضل متابعة أثر الاحتفاظ بالعملاء لاحقاً.
